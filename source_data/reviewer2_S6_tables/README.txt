Supplementary Tables S6a-S6i

These public tables contain the Reviewer 2 lineage, QC, scoring, DepMap, programme-overlap, matched-random, F3, protein-availability and SecAct/CNV audit outputs. Table S6h includes both protein availability and the endothelial RNA composition-proxy sensitivity. The primary protein analysis used 208 complete RNA-total-protein matched tumours with no imputation. The CNV family comprises 22,845 genes with BH correction; arm/segment testing was unavailable because sample-level calls were not retained.
